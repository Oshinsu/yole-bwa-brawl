ASSISTANCE · VERSION 3.2

SUPPORT

Un écran noir, une commande incomprise ou une sauvegarde absente ? Voici le chemin le plus rapide pour repartir en mer.

Diagnostic rapide

  • Rechargez la page puis vérifiez que WebGL et l’accélération graphique sont activés.
  • Sur mobile, jouez en paysage et fermez les applications lourdes en arrière-plan.
  • Pour le hors-ligne, terminez d’abord une visite complète avec une connexion active.
  • Si une ancienne version persiste, effacez les données du site puis rechargez.
  • La progression est locale : le mode privé et le nettoyage automatique du navigateur peuvent l’effacer.

Signaler un problème

Indiquez le modèle d’appareil, le navigateur, la version du jeu affichée dans le menu, les étapes pour reproduire le problème et, si possible, une capture sans information personnelle.

CRÉER UN TICKET DERNIÈRE VERSION

Les tickets GitHub sont publics. N’y placez ni adresse, ni numéro, ni document personnel.

Réinitialisation

Le menu Réglages permet de réinitialiser le pilotage, l’affichage et l’atelier. Une suppression complète des données du site efface également le Grand Tour, les replays et les préférences locales.
